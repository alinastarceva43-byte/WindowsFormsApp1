# Руководство пользователя
## 1. Главное меню

При запуске программы открывается окно **«Выбор задания»**. На нем расположены 8 кнопок. Нажатие на любую из них открывает отдельное окно с выполнением задания.

<img width="612" height="400" alt="image" src="https://github.com/user-attachments/assets/a15b140f-19ec-40cd-beda-3616b639455e" />

## Задание 1: Игра «Угадай число»

Введите число в текстовое поле и нажмите **«угадать!»**. Программа подскажет, больше или меньше загаданное число, и покажет счетчик попыток. Кнопка **«заново»** сбрасывает игру.

## Задание 2: Случайный цвет

Нажмите единственную кнопку **«случайный цвет»**, и фон окна мгновенно изменится на случайный оттенок.

<img width="595" height="394" alt="image" src="https://github.com/user-attachments/assets/cd134fa4-7956-4f33-9608-d69b081f666d" />

## Задание 3: Вывод сообщения (MessageBox)

Введите любой текст в поле ввода и нажмите кнопку **«отобразить»**. Поверх программы появится всплывающее окно с введенным текстом.

<img width="624" height="390" alt="image" src="https://github.com/user-attachments/assets/99108ea8-8bc1-4fe6-bbdd-91a16ee3f758" />

## Задание 4: Текст на кнопках

Введите слово в поле ввода, затем нажмите на любую из трех кнопок. Название нажатой кнопки изменится на ваш текст.

<img width="590" height="388" alt="image" src="https://github.com/user-attachments/assets/04c60c1f-e00a-4b35-a9b5-53197fcd2290" />

## Задание 5: Скрытые метки (Visible)

При запуске окна текст справа скрыт. Нажимайте на кнопки по очереди, чтобы открыть (сделать видимым) текст напротив каждой кнопки.

<img width="591" height="389" alt="image" src="https://github.com/user-attachments/assets/adf17661-1357-4eb7-afbd-238608def15e" />

## Задание 6: Блокировка элемента (Enabled)

Введите любой текст в поле ввода. При нажатии на кнопку **«блокировать»** поле ввода становится серым и недоступным для редактирования. При нажатии на кнопку **«разблокировать»** поле снова становится активным.

<img width="595" height="387" alt="image" src="https://github.com/user-attachments/assets/5fe072d4-ccd4-4356-a6a7-4ffff23d600d" />

## Задание 7: Приложение для заметок

Введите текст вашей заметки в большое многострочное поле. Нажмите кнопку **«сохранить»**, чтобы записать её в текстовый файл (.txt) на компьютере. Кнопка **«загрузить»** позволяет выбрать файл с диска и открыть его содержимое в программе.


<img width="531" height="370" alt="image" src="https://github.com/user-attachments/assets/0d43f4c3-53e9-450f-b0d3-790d63af029d" />

## Задание 8: Калькулятор

Используйте программу для выполнения арифметических операций с числами с плавающей точкой.
Введите числа, выберите нужное математическое действие и нажмите кнопку для расчета результата.
В программе предусмотрена защита от ввода некорректных данных и деления на ноль.
